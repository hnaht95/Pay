GHI NHANH BẰNG GIỌNG NÓI, ẢNH HOÁ ĐƠN

## Ghi chú cho người duyệt (App Review Notes)
Payso is a personal expense tracker. It does not hold, process or transmit money and never connects to bank accounts. Scanning a VietQR code only records the expense and opens the user's own banking app via its URL scheme; the transfer is confirmed by the user inside that app.

Payso does not require an account or sign-in. Data is stored on device (iCloud sync is a Pro feature).

How to test:
- Scan QR: tap "Quét QR" and scan any VietQR payment code (or tap "Dán STK" and paste text like "MB 0123456789 200k"). Payso opens the chosen bank app with recipient and amount prefilled; the expense is recorded.
- Voice: hold the "Nhập" button or tap the mic and say "50k cà phê".
- Groups (Nhóm chung): uses CloudKit sharing; requires an iCloud account. Create a group, add members by name to try splitting without a second device.
- Payso Pro: In-App Purchases "com.hnaht95.sochipay.pro.yearly" (auto-renewable, 1 year) and "com.hnaht95.sochipay.pro.forever" (non-consumable). Restore Purchases is in Settings › Payso Pro.
- Apple Pay auto-logging uses a Shortcuts automation the user sets up; nothing runs without user action.

The app is localized in Vietnamese (primary) and English (follows the device language).
